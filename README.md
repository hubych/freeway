# FREEWAY — мапа доступності

Учнівський соціальний проєкт Класичної гімназії при ЛНУ ім. І. Франка, створений у межах курсу лідерства Leave No One Behind Partnership.

FREEWAY показує на карті, чи доступні укриття та громадські місця (аптеки, школи, магазини) для людей на кріслах колісних, батьків з дитячими колясками та літніх людей.

## Що вміє демо-сторінка

- справжня карта центру Львова з мітками закладів;
- колір мітки показує оцінку доступності від 1 до 5, значок — тип закладу;
- клік по закладу в таблиці наближає його на карті й відкриває детальний опис;
- для недоступних місць є підказка, де найближче доступне;
- кожен заклад можна відкрити в Google Картах.

## Статуси доступності

| Оцінка | Статус | Що означає |
|---|---|---|
| 5 | Повністю доступно | Можна дістатися й користуватися самостійно |
| 4 | Доступно з допомогою | Є пандус чи ліфт, але інколи потрібен супровід |
| 3 | Частково доступно | Доступна лише частина приміщення |
| 2 | Важкодоступно | Без сторонньої допомоги не обійтися |
| 1 | Недоступно | Людина на кріслі колісному сюди не потрапить |

## Важливо

Це демонстраційна версія. Назви закладів, оцінки й описи вигадані для прикладу, а мітки стоять на справжніх вулицях орієнтовно. Справжні дані з'являться після перевірки учнями.

## Як змінити дані

Усі заклади записані у файлі `index.html` у списку `PLACES`. Щоб додати місце, скопіюйте один блок `{ id: ..., name: ..., ... }`, змініть назву, адресу, координати (`lat`, `lng` — їх можна взяти з Google Карт: правий клік по місцю → перші числа) та оцінку `score`.
